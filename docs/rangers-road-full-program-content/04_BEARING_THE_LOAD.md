# Chapter IV — Bearing the Load
## Weeks 13–16
**Theme:** Carry what is yours to carry.  
**Trial:** The Burden Trial.

# Forge A — Carry Strength
- Box Squat — 3 x 6
- Bench Press — 3 x 5–6
- Assisted Pull-Up — 3 x 6–8
- Suitcase Carry — 4 x 45 sec/side
- Step-Up — 3 x 8/leg
- Front-Hold Carry — 3 x 30–45 sec
- Side Plank — 2 x 30–45 sec/side

# Forge B — Functional Strength
- Goblet Squat — 3 x 8
- Supported Reverse Lunge — 3 x 6–8/side
- One-Arm DB Row — 3 x 10
- Push-Up — 3 submaximal sets
- Farmer Carry — 4 x 45–60 sec
- Glute Bridge — 3 x 12
- Bear-Hug Carry — 3 x 30–45 sec
- Elevated Light Hinge — 2–3 x 6–8 only if back tolerates

# Leadership — Ownership Without Martyrdom
Identify -> Own -> Communicate -> Complete -> Ask for help before silent failure.

# Fieldcraft
Learn:
- pack weight close to body
- essential vs unnecessary gear
- organization
- hydration planning
- footwear inspection
- blister prevention
- load distribution

# Hearth Mission
Own one recurring family responsibility for the month.

# Daughter Quest
Outdoor walk with each person responsible for a small personal pack.

# Capability Goal — Carry a Child One Mile
Milestones:
1. 30 lb x 1 min
2. 30 lb x 3 min
3. 30–40 lb x 5 min
4. 3-min carry / 2-min unloaded intervals
5. 1/4 mile total carried
6. 1/2 mile total carried
7. 1 mile total with planned switches/rest

# Burden Trial
1. 3-mile ruck with 10–15 lb appropriate to readiness.
2. Carry circuit x 3:
   - farmer carry 60 sec
   - rest 60 sec
   - suitcase carry right 45 sec
   - suitcase carry left 45 sec
   - front-hold carry 45 sec
   - 10 step-ups/leg
3. Five clean elevated light pickups/hinges with safe technique and no meaningful symptom increase.
4. Write three items under **I am responsible for** and three under **I am not responsible for**.
5. Read Galatians 6:1–5 and reflect: **What burdens should I help carry, and what responsibilities must I stop avoiding?**
