# Fieldcraft — Navigation I
Across the month learn:
- cardinal directions
- orienting without immediately using GPS
- trail-map basics
- trail blazes
- estimating distance
- landmarks
- choosing turnaround points

Field mission: before one Saturday walk, study the trail map and predict direction, landmark, distance to a turn, and location of start; confirm afterward.

Daughter quest: let daughter navigate one simple marked portion.

# The Three-Mile Trial
1. Walk 3 continuous miles; record time, splits if available, HR, RPE, knee/back discomfort, 5-min recovery.
2. 30-lb suitcase carry — 60 sec right, 60 sec left; record grip/core/posture difficulty.
3. Three-flight stair test at steady pace if appropriate; rate breathlessness 1–10.
4. Leadership reflection: **When someone in my family speaks, do they experience me as attentive?** Name one behavior to change.
5. Prayer: read Psalm 121 and pray specifically for spouse, each child, future family, and personal growth.
