# Mind Framework — Practical Problem Solving
Observe -> Simplify -> Use what you have -> Act -> Reassess.

# Leadership Skill — Teaching
Explain simply -> demonstrate -> let learner try -> correct one thing -> allow independent attempt.

# Daughter Quest
Teach one practical skill (knot, map reading, packing, first aid, basic maintenance, etc.) and record what she can do independently afterward.

# Fieldcraft Trial
1. Plan and complete a 3–5 mile route.
2. Before leaving record expected time, distance, landmarks, and turnaround criteria.
3. At two points estimate location before GPS.
4. At one junction explain route choice.
5. Complete one practical skill task:
   - knot
   - first-aid scenario
   - safe gear repair
   - tool competency
   - navigation problem
6. Complete 10–15 min of light loaded carry/ruck plus 60-sec suitcase carry each side and 60-sec farmer carry.
7. Reflect: **What am I now able to do that I would have avoided six months ago?**
