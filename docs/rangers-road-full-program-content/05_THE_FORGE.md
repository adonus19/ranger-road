# Chapter V — The Forge
## Weeks 17–20
**Theme:** Strength must be built, not displayed.  
**Trial:** The Forge Trial.

This is the campaign's most strength-focused block, but remains submaximal and pain-aware.

# Forge A — Strength
- Squat variation — 4 x 5
- Bench Press — 3 x 5
- Assisted Pull-Up — 4 x 5
- Supported Split Squat — 3 x 8/side
- Suitcase Carry — 3 x 60 sec/side
- Side Plank — 3 x 30–45 sec/side

# Forge B — Strength
- Goblet Squat — 3 x 10
- Step-Up — 3 x 10/leg
- One-Arm DB Row — 4 x 8/side
- Push-Up — 3 submaximal sets
- Farmer Carry — 4 x 60 sec
- Elevated Light Hinge — 3 x 8 only if symptom-free
- Single-Leg Balance — 2 x 30 sec/side

# Saturday Work-Capacity Circuit
Start Week 17 with 3 rounds; Weeks 18–19 use 4 rounds if recovery is good:
- 10 goblet squats
- 8 push-ups
- 8 rows/side
- 30-sec farmer carry
- 2-min walk
Rest as required; never race to failure.

# Leadership Skill — Emotional Regulation
Notice -> Name -> Delay -> Choose -> Repair.

# Fieldcraft — Tool Competence
Practice:

- safe axe/maul handling

- maintenance
- fatigue awareness
- stopping before form/control deteriorate

This is practical tool use, not axe conditioning.

# Hearth Mission
For one week, deliberately practice calm response when tired or frustrated. Record only notable moments and any needed repair.

# Forge Trial
After adequate warm-up, use clean submaximal tests:

1. Squat variation: one clean set of 8 at a known training weight; stop before grinding.
2. Bench Press: one clean set of 8 at controlled effort.
3. Assisted Pull-Up: test lightest assistance band that permits clean reps; record reps.
4. Push-Ups: one max clean set; stop when form breaks.
5. Farmer Carry: fixed known load for max clean time, capped at a sensible limit (e.g. 2 min).
6. Work-capacity test — 3 rounds:
   - 10 squats
   - 10 push-ups
   - 10 step-ups/leg
   - 8 rows/side
   - 60-sec farmer carry
   - 2-min walk
   Record time and RPE.
7. Reflection: **Has becoming stronger made me more useful, or simply more interested in strength?**
