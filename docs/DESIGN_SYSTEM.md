# Design System

## Visual Direction

Classic ranger field journal + restrained fantasy adventure.

Not:
- cosplay
- medieval UI clutter
- fake parchment everywhere
- neon game HUD
- bodybuilding app aesthetic

Chosen direction: **Forest Light**. A painted dawn forest band holds the chapter, and the day's orders sit on warm paper below it. The Road page borrows the Night Atlas route line: a thin winding trail, a gold Today mark, and a ring for the trial.

Themes: light by default. When the device is set to dark mode, the app switches to a dark variant drawn from the Night Atlas palette.

## Mood

- weathered
- grounded
- forested
- capable
- quiet
- disciplined
- warm hearth contrast
- trail/terrain motifs

## Semantic Use

- Green / Pine: normal / ready / progression
- Gold: chapter/trial emphasis
- Stone: secondary information
- Ember: warning / caution
- Red should be reserved for meaningful pain/safety states

## Typography

Direction:
- serif or humanist display face for chapter titles
- highly readable sans-serif for UI
- avoid overly decorative fantasy fonts

In use: Wittgenstein for chapter names, headings, and numerals; Noto Sans at a semi-condensed width for everything read or tapped. Both are self-hosted so the app looks the same offline.

## Imagery

Exercise assets:
- consistent illustrated human model
- clean neutral background
- 3–5 movement frames
- subtle directional arrows
- muscle maps showing front and back from the neck down, without a head or face

Campaign imagery:
- forests
- trails
- ridgelines
- field journals
- maps
- camp/hearth motifs

## Motion

- restrained
- purposeful
- map progression
- subtle completion transitions
- image-sequence exercise loops
- no confetti for prayer or faith activity
