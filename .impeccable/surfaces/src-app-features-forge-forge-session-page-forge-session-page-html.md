## Scope

Chapter I Forge A/B and Restoration player. Mode: Operate. The app records actual sets, modifications, pain, and a session outcome in local history.

## Audience and job

One person using a phone during training. He needs to read the current movement and dose at a glance, record what happened, find form help without leaving the workout, and stop safely when pain or readiness requires it.

## Direction contract

THESIS: Current Set. The selected movement and one set command the view; secondary controls remain reachable but quiet.

OWN-WORLD: Forest Light. A dark brand bar leads into warm paper. Large book-serif exercise and set type, fine rules, restrained sage labels, and a pine primary action carry the page. Readiness and pain are named in words.

FIRST VIEWPORT: Back to Forge, workout and exercise position, oversized exercise name, prescription, set position, large target dose, planned-load field, Quick Help, Pain, Substitute, and a docked Complete set action are legible at phone width. Actual reps or seconds appear in a short confirmation when Complete set is tapped.

FORM: Current Set, selected by the user from `.impeccable/mocks/decision/forge-current-set.png`. The user also approved the Box Squat illustrated media prototype. Every muscle map omits the head and face.

## Related behavior

- Same-day readiness precedes training. Red blocks strength; Restoration can remain available if appropriate.
- A draft resumes from the saved exercise and set. Every prescribed set is marked done or skipped before a completed session is stored. Stopping retains partial work.
- The rest clock shows elapsed time; Chapter I gives no fixed rest dose. Previous load is display-only.
- Quick Help shows a generated sequence, short steps, feel and mistakes; Full Guide adds catalog details and a neck-down map.
- Pain persists immediately, and a level of 5 or more ends strength work. A written substitution records what the person actually did without creating a new prescription.

## Local visual decisions

The set target and exercise title use more scale than the usual DESIGN.md headings because a person must read them while moving. Instructional illustrations and neck-down maps are the only images beyond the decorative forest painting.
