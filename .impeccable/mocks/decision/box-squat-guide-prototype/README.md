# Box Squat guide media prototype

This is a review set, not a shipped exercise asset. It follows `docs/EXERCISE_LIBRARY_SPEC.md`, `docs/DESIGN_SYSTEM.md`, and the Box Squat entry in `docs/rangers-road-full-program-content/EXERCISE_CATALOG.md`.

## Review images

- `box-squat-sequence-v2.png`: four consistent movement frames in order: stand, descend, lightly contact the box, stand.
- `box-squat-muscle-map.png`: front and back body maps. Dark pine marks primary quadriceps and glutes; lighter moss marks secondary adductors and trunk stabilizers.

The individual `box-squat-frame-v2-0.png` through `box-squat-frame-v2-3.png` and `box-squat-map-0.png` / `box-squat-map-1.png` are crops for a possible mobile guide. Every PNG carries its generation prompt as embedded metadata; the prompt files are included here too.

## Review before use

- Confirm that the low box height and light contact frame communicate the intended controlled squat. A still image cannot prove that the user maintains tension or avoids sitting fully.
- Have a qualified coach or clinician review the movement positions and muscle highlights before using these as instructional guidance, especially for a pain-aware program. The images are generated illustrations, not a clinical anatomy reference.
- The model is illustrated as visibly muscular; validate whether that feels approachable for the program's returning trainee before applying this style to the remaining exercises.
- When approved, produce production-sized WebP files for offline use, keep the PNG sources, and wire the filenames into the data-driven exercise guide. Do not treat these review PNG paths as app URLs.
